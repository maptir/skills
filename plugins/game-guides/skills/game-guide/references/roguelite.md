# Roguelite, deckbuilder, extraction

## Where the irreversible decisions hide

The run resets, so scarcity works differently — but it is still the spine:

- **Meta-progression currency.** Permanent unlocks bought with a currency that
  accumulates slowly. The unlock *order* matters enormously for how painful the
  first ten hours are, and it is the highest-value thing a guide can give.
- **Unlock pollution.** Many of these games add cards, items or weapons to the
  shared pool as you unlock them. Unlocking a weak option permanently dilutes
  every future run's offers. Guides that ignore this actively harm the player.
- **In-run one-way picks.** Every reward screen is a fork; the run's identity is
  set within the first few choices.
- **Extraction-specific:** gear brought in can be lost for good. Loadout value
  versus risk is the whole decision.

## Numbers to hunt

Cost of each meta unlock and typical currency per run · which unlocks enter the
shared pool versus which are opt-in · how many choices a run offers before it is
committed · the difficulty ramp and where new players actually die · run length.

## Tabs that usually earn their place

The loop and the budget · Meta-unlock order, ranked, with the pollution warning marked ·
How a run's identity forms and when to commit · Archetypes with their key
enablers · The first-pick heuristics (what to take when nothing has come
together yet) · Common losing patterns · Difficulty ladder and when to climb.

## Advice traps

- **Do not teach the optimal line first.** These games are learned by losing.
  Teach the decision procedure — "take the thing that answers your current
  weakness, not the thing with the biggest number" — which survives the game's
  randomness, where a fixed list does not.
- **Tier lists rot fast** and depend on the unlock pool. If you give one, say
  what it assumes and which patch it reflects.
- **Say when to stop optimising.** Many of these games have a difficulty tier
  where the meta genuinely changes. Below it, "play what is fun" is correct
  advice and worth stating outright.
- **Distinguish "strong card" from "strong pick right now".** A pick's value is
  relative to the deck or build already assembled; context is the lesson.
